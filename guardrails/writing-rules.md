# Writing rules

The rules live once, in the Cerulea build package. Read them at
`cerulea-build/04-guardrails/writing-rules.md`.

Holding a second copy here let the two drift apart. The term check also
reads this tree, and a copy of the rules names the very words the rules
retire, which the check then reports. One copy removes both problems.

The check itself runs from this repository:

```
bash ../cerulea-build/04-guardrails/term-check.sh .
```
